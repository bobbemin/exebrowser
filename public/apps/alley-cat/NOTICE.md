# Alley Cat (1984)

IBM / Synapse Software. Rights now held by IBM (Synapse Software no longer exists).

## Why this is hosted here

Abandoned software: Alley Cat is not sold in any form today. It is hosted on the
same footing as the Internet Archive's software collections. That is a practical
position, not a legal claim; abandonment does not transfer copyright. The page
carries no advertising. If the rights holder asks, it is removed within 48 hours:
https://exebrowser.com/takedown/

Not sold: GOG, Steam and Antstream checked 2026-10-05; Alley Cat is not sold in any form and Synapse Software ceased trading in the 1980s.

## Source

Retrieved 2026-10-05 from https://archive.org/details/msdos_Alley_Cat_1984
