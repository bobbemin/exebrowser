# The Incredible Machine (1992)

Sierra On-Line (Dynamix). Current rights holder unclear: Sierra's catalogue passed through Vivendi to Activision.

## Why this is hosted here

Abandoned software: The Incredible Machine is not sold in any form today. It is hosted on the
same footing as the Internet Archive's software collections. That is a practical
position, not a legal claim; abandonment does not transfer copyright. The page
carries no advertising. If the rights holder asks, it is removed within 48 hours:
https://exebrowser.com/takedown/

Not sold: GOG, Steam and Antstream checked 2026-10-05; not sold in any form (GOG's Incredible Machine Mega Pack of later versions has been withdrawn).
