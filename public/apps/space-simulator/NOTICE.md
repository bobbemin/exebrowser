# Microsoft Space Simulator (1994)

Microsoft. Rights now held by Microsoft.

## Why this is hosted here

Abandoned software: Microsoft Space Simulator is not sold in any form today. It is hosted on the
same footing as the Internet Archive's software collections. That is a practical
position, not a legal claim; abandonment does not transfer copyright. The page
carries no advertising. If the rights holder asks, it is removed within 48 hours:
https://exebrowser.com/takedown/

Not sold: GOG, Steam, Microsoft Store and Antstream checked 2026-10-05; not sold in any form (the Steam game named Space Simulator is an unrelated 2017 title).
