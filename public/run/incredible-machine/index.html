About The Incredible Machine

The Incredible Machine first came out in late 1992 and started a long series. It has 87 puzzles, each with a password so you can come back to it, plus a freeform mode where you play with every part or build puzzles of your own. The physics include gravity and air pressure, and nothing is random: the same machine always runs the same way, so a failed attempt tells you exactly what to change. Most puzzles have more than one solution. Kevin Ryan wrote it in nine months on a budget of $36,000.

Tips for getting started

Press Esc for the control panel. Note each puzzle's password as you go so you can return to it.
