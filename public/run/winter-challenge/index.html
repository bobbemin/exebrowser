About The Games: Winter Challenge

Winter Challenge was not licensed by the IOC, but it is built around the Winter Olympics, with an opening ceremony and standings. MindSpan used a simple 3D engine for the slopes and tracks, so the downhill and the bobsled run are courses with real slopes rather than flat scrolling. Each event asks for something different: finding the fastest line on the downhill, luge and bobsled, pacing yourself in cross-country and biathlon, timing on the ski jump, and fast tapping in speed skating. In Tournament mode the computer rivals can be set from Amateur to World Class. A Mega Drive version followed, and Accolade made The Games: Summer Challenge in 1992.
